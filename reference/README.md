# UI References — Source of Truth

Drop all branding and design references here. These drive the app's theme/token layer
and are authoritative for every UI decision.

## Folders
- `logos/`        — D-LYFT and GRYNX logos (SVG preferred, plus PNG @1x/@2x)
- `screenshots/`  — UI reference screenshots / mockups (name by screen)
- `fonts/`        — font files + a note on which weights to use where
- `colors/`       — palette (hex), or a swatch image / tokens file
- `icons/`        — any custom iconography

## When you add assets
Tell me what's in here and I'll generate a `theme.ts` token set (colors, type scale,
spacing, radii) so every platform stays visually consistent.
